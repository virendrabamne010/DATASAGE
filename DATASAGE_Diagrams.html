Module Breakdown

Every module, class, method, and file in DATASAGE explained in detail

🧠 Core — Analyzer Class

datasage/core/analyzer.py (~430 lines)

The main orchestrator. All user interaction happens through this single class. It wires together all sub-modules using a fluent API (method chaining) pattern.

  • clean() — delegates to 3 cleaner classes in sequence
  • analyze() — runs all 4 insight analyzers, returns a dict
  • visualize() — saves PNG charts to ./output/ directory
  • generate_report() — writes PDF or .txt report file
  • summarize() — executive summary with actionable recommendations
  • reset() — restores the original unmodified DataFrame
  • info() — prints shape, dtypes, memory, and duplicate count
  • Stores cleaning_stats and analysis_results as instance dicts

🧹 Cleaner — 3 Classes

datasage/cleaner/ (3 files)

Handles all data quality problems. Each class can be used standalone or is called automatically by Analyzer.clean().

  • MissingValueHandler — analyze() scans all columns for NaN. handle() supports: drop_col (default if >50%), drop_row, mean, median, mode, forward_fill
  • OutlierDetector — IQR fence: Q1−1.5*IQR to Q3+1.5*IQR. Z-score: mean ± 3*std. Methods: detect(), remove_outliers(), cap_outliers()
  • DuplicateRemover — analyze() returns count, remove() calls drop_duplicates()

🔍 Insights — 4 Analyzers

datasage/insights/ (4 files)

Generates statistical intelligence from the cleaned DataFrame. Results are returned as nested dicts and stored in Analyzer.analysis_results.

  • StatisticsAnalyzer — count, mean, median, std, min, max, Q25, Q75, skewness, kurtosis per numeric column
  • CorrelationAnalyzer — Pearson / Spearman / Kendall matrix, flags high-correlation pairs above 0.7 threshold
  • CategoryAnalyzer — top N (default 5) value counts per categorical column
  • TrendAnalyzer — scipy.stats.linregress(): slope, R², p-value. Labelled significant if p < 0.05

📊 Visualization — 3 Plotters

datasage/visualization/ (3 files)

Generates matplotlib and seaborn charts saved as PNG files. The Streamlit app additionally uses Altair for interactive charts.

  • ChartGenerator — bar_chart(), line_chart(), scatter_chart(), pie_chart(). All use seaborn whitegrid style
  • DistributionPlotter — histogram(), kde_plot(), box_plot(), violin_plot(). Saves to configured output directory
  • HeatmapGenerator — correlation_heatmap() using seaborn. Auto-detects numeric columns
  • All use save_figure(fig, path) at config.DPI (100)

📄 Report — 2 Generators

datasage/report/ (2 files)

Produces professional downloadable reports combining statistics, embedded charts, and data-driven recommendations.

  • PDFReportGenerator — ReportLab: custom stylesheet, title page with timestamp, alternating-row tables, embedded PNG charts, recommendations page. build() writes PDF
  • TextReportGenerator — Plain .txt with section dividers, key-value tables, dataset overview, stats, correlations, categories
  • Both called via Analyzer.generate_report(filepath, format="pdf"/"txt")

🌐 Streamlit Web App

streamlit_app.py (757 lines)

Full-featured interactive web dashboard for non-technical analysts — no coding required.

  • CSV and Excel upload with sheet picker and malformed-CSV fallback
  • Animated SVG health score gauge (0–100) based on data quality
  • Schema inference with type coercion suggestions per column
  • Per-column cleaning controls in sidebar with live preview
  • Feature importance bar chart using Altair (variance, correlation, missingness)
  • Executive summary, outlier row preview, wellness dashboard tabs
  • Upload history persisted to JSON, light/dark theme toggle
  • One-click download: cleaned CSV and PDF report

⚙️ Config System

datasage/config.py (dataclass singleton)

A centralized dataclass singleton imported by all modules — the single source of truth for every threshold and setting.

  • MISSING_THRESHOLD = 0.5 — drop cols with >50% NaN
  • OUTLIER_METHOD = "iqr" (alternative: "zscore")
  • IQR_MULTIPLIER = 1.5 — standard Tukey fence
  • ZSCORE_THRESHOLD = 3.0 — 3-sigma rule
  • CORRELATION_THRESHOLD = 0.7 — high-corr cutoff
  • TOP_CATEGORIES_COUNT = 5
  • FIGURE_SIZE = (12, 6), DPI = 100

🐳 DevOps and Deployment

Dockerfile, docker-compose.yml, .github/workflows/

Production-ready containerization and CI/CD pipeline for real-world deployment at any scale.

  • Dockerfile — builds Streamlit image, exposes port 8501
  • docker-compose.yml — multi-service orchestration
  • .github/workflows/ci.yml — automated pytest on every push/PR
  • pyproject.toml — PEP 517 packaging with setuptools
  • Published to PyPI as the "datasage" package
  • MIT License, Python 3.10+ support

Technology Stack

Complete list of all libraries, frameworks, and tools used in DATASAGE

📊 Data Processing

pandas 1.3+ numpy 1.21+ scipy 1.7+ openpyxl 3.0+ xlrd 2.0+

pandas for all DataFrame operations. scipy.stats.linregress for trend detection. openpyxl and xlrd parse .xlsx and .xls files.

📈 Visualization

matplotlib 3.4+ seaborn 0.11+ altair 5.0+

matplotlib + seaborn generate static PNG charts saved to disk. Altair creates interactive Vega-Lite charts inside the Streamlit web app.

🌐 Web Interface

streamlit 1.30+

Streamlit powers the entire web UI: file upload, metrics, charts, download buttons, sidebar controls, and the custom SVG animated health gauge — all in pure Python.

📄 Report Generation

reportlab 3.6+

ReportLab renders professional PDF reports with custom paragraph styles, alternating-row-colour tables, embedded PNG chart images, and a timestamped title page.

✅ Code Quality and Testing

pytest 7.0+ pytest-cov black 22.0+ flake8 4.0+ mypy 0.900+ isort 5.0+

Full test coverage via pytest. black for code formatting, flake8 for linting, mypy for type-checking, isort for import ordering.
